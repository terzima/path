# Path Privacy Policy

Updated October 8, 2026. Applies to Path 1.0.0.

## Your data

Path stores folders, tasks, notes, checklists, schedules, and completion history locally on your device. Path has no account system or server sync.

Path does not send your task data to the developer. The app does not include advertising, analytics, or tracking services.

## Files you choose

CSV import reads the file you select using the system file picker. Path uses its contents to create or update your local tasks. Imported files may remain in the app's temporary storage until cleared by the system.

Backup creates a JSON file and opens the system share sheet. Your chosen destination may receive the file under its own privacy policy. Exported backups may remain in the app's temporary storage until cleared by the system. Backup currently contains folders, tasks, and recurring completion history; it does not include checklist items, and Path does not yet restore backup files.

## Retention and deletion

Your task data remains in the app until you delete it or delete the app. You can delete tasks and project folders within Path. Deleting the app, rather than offloading it, removes its local data. Previously exported files remain wherever you saved or shared them.

Device backups and operating-system diagnostics are managed separately by Apple and your device settings.

## Changes

Changes to how Path handles data will be reflected in an updated policy and a future app update.
