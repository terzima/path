# Path App Store screenshots

Six actual app screens, using fictional sample tasks, captured from the standalone version 1.0.0 release build on iOS simulators. No personal task data is included. JPEG files are opaque and keep the native device resolution.

- iphone-medium: 1206 × 2622 pixels (iPhone 17 Pro).
- iphone-large: 1320 × 2868 pixels (iPhone 17 Pro Max).

Upload files 01–06 in order to the matching iPhone screenshot display slots under App Store Connect → Path → iOS App version → App Previews and Screenshots. Use the media manager if the second display size is hidden. Upload each size as its own set; do not mix sizes in a single slot. These are screenshots, not App Preview videos.

Order: daily Overview, Upcoming, project folder, task details and checklist, rescheduling with cascade enabled, completed-task Archive. The rescheduling preview does not apply the move.
